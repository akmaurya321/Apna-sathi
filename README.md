# अमीन साथी

एक सरल, मोबाइल-फ्रेंडली वेबसाइट जहाँ अपनी जरूरी साइटों के लिंक ब्राउज़र बुकमार्क की तरह रखे जा सकते हैं।

## उपयोग

1. मुख्य श्रेणी खोलें।
2. अपनी जरूरत के अनुसार उप-श्रेणी बनाएँ।
3. उस उप-श्रेणी में लिंक का नाम और वेबसाइट पता जोड़ें।
4. सेव किए गए लिंक पर टैप करके वेबसाइट खोलें।
5. खोली गई आखिरी तीन साइटें मुख्य स्क्रीन के ऊपर दिखेंगी।

छह मुख्य श्रेणियाँ पहले से दी गई हैं। कोई सरकारी वेबसाइट या उप-श्रेणी पहले से नहीं जोड़ी गई है; उपयोगकर्ता केवल वही जोड़ता है जिसकी उसे जरूरत है। उप-श्रेणियों और लिंक को बाद में बदला या हटाया जा सकता है।

## डेटा और गोपनीयता

जोड़े गए उप-श्रेणी और लिंक उसी browser और device के local storage में सेव होते हैं। कोई login या server नहीं है। Browser data साफ़ करने पर सेव किए गए लिंक भी हट सकते हैं।

मुख्य श्रेणियों की संदर्भ तस्वीरें Unsplash से लोड होती हैं; तस्वीरें दिखाने के लिए Internet connection चाहिए।

## चलाना और प्रकाशित करना

`index.html` खोलकर उपयोग करें, या GitHub Pages जैसे static hosting पर प्रकाशित करें। Internet के बिना भी पहले से सेव किए गए लिंक सूची में दिखेंगे; लिंक खोलने के लिए Internet आवश्यक है।

## परियोजना की फाइलें

- `index.html` — ऐप का ढाँचा
- `assets/css/style.css` — मोबाइल-फ्रेंडली डिज़ाइन
- `assets/js/config.js` — छह स्थायी मुख्य श्रेणियाँ
- `assets/js/app.js` — उप-श्रेणियाँ, लिंक और हालिया साइटें
- `assets/js/storage.js` — browser local storage
- `sw.js` — offline app shell
